# ops: سند بیزینسی

> سند فنی: [TECHNICAL.md](TECHNICAL.md)

## ۱. چه کسی با ops کار دارد
- **صاحب پروژه** (تنها توسعه‌دهنده و اپراتور): دیپلوی، ریلیز، پاسخ به بازبینی فروشگاه‌ها، بکاپ.
- **کاربر نهایی** فقط اثرش را می‌بیند: در دسترس بودن سایت و API، آمدن پیامک و پوش، سرعت.

## ۲. قانون‌های عملیاتی
- **کاربر واقعی داریم؛ فقط تغییر افزایشی.** هیچ migration مخربی، هیچ حذف داده‌ای.
- هر دیپلوی: اول dump، بعد rebuild، بعد reload nginx. بدون reload حدود یک دقیقه قطعی 502 تجربه شده است.
- هر دستور روی prod و هر خواندن داده prod با اجازه کاربر.
- ریلیز اپ‌ها فقط از CI با تگ؛ APK دستی منتشر نمی‌شود. تگ اپ مشتری (`client-v*`) با تایید کاربر.
- push فقط وقتی کاربر بگوید.
- رازها هرگز در git یا سند نیستند؛ رمز root سرور در تاریخچه git هست و باید چرخانده شود (مساله باز).

## ۳. هزینه‌ها و محدودیت‌ها
- هزینه ثابت ماهانه (طبق `backend/PLANS.md`): سرور حدود ۶۰۰٬۰۰۰ و هاست و دامنه حدود ۱۶۷٬۰۰۰ تومان.
- پیامک تنها هزینه متغیر است (حدود ۱۷۰ تومان هر پیامک).
- سهمیه GitHub Actions محدود است؛ این ماه تمام شده، پس ریلیز تا ماه بعد از CI ممکن نیست.
- سایت بیمه‌ها فقط از داخل ایران باز می‌شوند؛ n8n باید روی سرور ایران اجرا شود.
- بار: تست بار ۲۰۲۶-۱۰-۲۹ در `docs/LOAD_TEST_2026-10-29.md`.

## ۴. بکاپ و بازیابی
بکاپ رمزدار شبانه به تلگرام؛ کلید رمز بیرون از سرور نگه داشته می‌شود. dump قبل از هر دیپلوی.

## ۵. کانال‌های توزیع از دید ops
هر تگ اونر سه APK (سایت، بازار، مایکت) و هر تگ مشتری دو APK (سایت، فروشگاه) می‌سازد؛ نسخه سایت روی noobatyar.ir و تلگرام و GitHub Release می‌رود، نسخه‌های فروشگاهی دستی در پنل مایکت و بازار بارگذاری می‌شوند. جزییات: [channels](../business/channels.md).

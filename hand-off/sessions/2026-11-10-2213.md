## Decisions (and why)
- مرکز جدول جدا نشد: مسیر claim همان ردیف و لینک عمومی را نگه می‌دارد.
- پیگیری تماس در جدول کنار (`CenterOutreach`) است تا جدول اصلی کسب‌وکار دست نخورد (فقط یک ستون `origin` افزایشی).

## Problems / dead ends
- سایت‌های بیمه از مک (بیرون ایران) باز نمی‌شوند (`tamin.ir` geo-block، بقیه خطای TLS)؛ از سرور ایران (`DEPLOY_HOST=194.146.69.137 bash scripts/remote.sh ...`) دانا و تامین باز می‌شوند. `scripts/remote.sh` اجرایی نیست؛ با `bash` اجرا کن.
- دانا به curl ساده 404 می‌دهد؛ جعل User-Agent توسط سیستم «دور زدن bot check» رد شد و انجام نشد. راه درست: لینک گوگل → صفحه `appsef.dana-insurance.ir/subportal` → API JSON خود صفحه.
- geocoding OSM Nominatim روی آدرس کامل ۰ از ۵ جواب داد (فقط مرکز شهر). برای دقت بهتر کلید API نشان/بلد لازم است.
- پورت 5678 دست `peyk_n8n` (پروژه دیگر) است؛ n8n ما روی 5679.
- `n8n execute` داخل کانتینر: `docker exec -e N8N_RUNNERS_BROKER_PORT=5680 ...`. فایل‌های `docker cp` شده را باید با `docker exec -u 0` پاک کرد. `host.docker.internal` باید در `ALLOWED_HOSTS` باشد وگرنه 400.
- حساب owner در n8n را نمی‌شود من بسازم؛ کاربر باید در `http://localhost:5679` بسازد و workflow را روشن کند.
- `zsh`: `echo ======` خطا می‌دهد (علامت `=`)؛ pattern گلوب بدون quote هم.

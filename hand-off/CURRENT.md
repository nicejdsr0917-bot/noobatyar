# وضعیت فعلی

## هدف
اپ مشتری اندروید (`mobile_client/`، برنچ `mobile-client`) را زیبا و روان کنیم: طراحی و انیمیشن کل اپ با رنگ و لوگوی برند (بنفش)، و نقشه‌ی سریع. **فقط اندروید**؛ iOS بیلد یا بررسی نشود.

قاعده‌ی همیشگی: فقط تغییر افزایشی، چون کاربر واقعی داریم.

## وضعیت
- **کامیت شده، push نشده:** `c617ea0` (بک‌اند پروفایل) و `3a6b1e9` (اپ). develop و main دست نخورده‌اند.
- **انجام شده و روی امولاتور دیده شده:**
  - صفحه‌ی مرکز: هدر عکس‌دار یا گرادیان، انیمیشن بسته شدن با رفتن اسم به تولبار (تولبار به رنگ تم)، انتخاب روز و ساعت، سوایپ رفرش.
  - تب «پروفایل» به جای «بیشتر»: عکس، ویرایش اسم و عکس، آیکن تب همان عکس پروفایل.
  - آیکن صنف به جای حرف اول.
  - دکمه‌های مبدا و مقصد روی نقشه‌ی مرکز.
  - ذخیره‌ی کاشی نقشه روی گوشی (۳۰ روز، ۱۰۰ مگابایت) و پیش‌دانلود اطراف شهر.
  - صفحه‌ی خطا و خالی متحرک.
- **امتحان نشده:** انتخاب عکس از گالری؛ روی امولاتور فقط آپلود از API امتحان شد.
- **تست‌ها:** بک‌اند visitor/api/reviews ۱۲۸ تست سبز. اپ: `testLocalDebugUnitTest` سبز.
- **قبلی (هنوز درست):** MapLibre و Map.ir ساخته شد ولی برگشت خورد (`0bc39e3`). نقشه‌ها MapCompose با کاشی HOT و `TileRecolor` هستند.

## قدم‌های بعدی
1. push برنچ `mobile-client` (فقط اگر کاربر بگوید).
2. دیپلوی بک‌اند با migration `visitor/0014_visitor_avatar`. بدون آن، اپ نسخه‌ی اصلی نمی‌تواند اسم یا عکس را عوض کند.
3. طراحی دوباره‌ی صفحه‌های کاوش، «نوبت‌های من» و «نشان‌شده‌ها» با همین سبک: کارت گرد، کاشی آیکن رنگی، ورود پلکانی، فشار با `pressScale`.
4. تصمیم کاربر: فیلد جدا «عکس کاور» برای مرکز؟ الان هدر از `logo` استفاده می‌کند و لوگوی مربعی بزرگ و بریده می‌شود.
5. کلید Map.ir (از corp.map.ir) برای نقشه‌ی برداری داخلی؛ یا پراکسی کاشی روی سرور خودمان، اگر سرور داخل ایران است.
6. از قبل: داده‌ی واقعی بیمه‌ها؛ نمایش فاصله و زمان رانندگی به اونر (کاربر هنوز نگفته کجا).

## مسائل باز
- ⚠️ **قبل از دیپلوی:** migrationهای `visitor/0014`، `appointment/0017`، `banners/0002`، `business/0035`، و migrationهای قبلی P2. `seed_insurances` اجرا شود. `ZIBAL_MERCHANT_ID` در `.env` باشد. `seed_demo_businesses` فقط برای محلی است.
- 🔒 رمز root سرور در تاریخچه‌ی git است و باید عوض شود.
- `PushMessagingService` اپ کلاینت ثبت نشده است؛ منتظر فایل Firebase.
- وب توکن `Visitor` را روی لیست و جزئیات کسب‌وکار نمی‌فرستد.
- **قاعده‌ی متن اپ:** کوتاه و بدون ئ ء ٔ أ. ثابت `BOOKING_BLOCKED_NOTICE` را عوض نکن.
- **محیط (Windows 11):**
  - امولاتور LDPlayer است (`emulator-5554`)، و یک گوشی Redmi هم وصل است؛ همیشه `adb -s emulator-5554`.
  - **وای‌فای امولاتور را خاموش نکن**، چون adb قطع می‌شود. برای تست آفلاین از `global_http_proxy_*` استفاده کن (یادداشت سشن).
  - `adb reverse tcp:8000 tcp:8000` بعد از هر ری‌استارت امولاتور.
  - بیلد: `./gradlew.bat :composeApp:assembleLocalDebug :composeApp:testLocalDebugUnitTest` با `ANDROID_HOME`.
  - کش داخل حافظه‌ی بک‌اند فقط با ری‌استارت سرور پاک می‌شود.
- overlay پین‌ها در RTL باید اندازه‌ی کامل والد را بگیرد.

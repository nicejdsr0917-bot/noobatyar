## مسائل باز
- 🔒 رمز root سرور در تاریخچهٔ git است و باید عوض شود.
- **بعد از rebuild وب روی prod حتماً `nginx -s reload` بزن**، وگرنه 502 (حافظهٔ deploy-ops).
- جزئیات کمپین پیامک تبلیغاتی (`promo-sms/<id>/`) هنوز شمارهٔ کامل گیرنده را به اونر نشان می‌دهد. بپرس که آنجا هم ماسک شود یا نه.
- جستجوی بیمه با تایپ فارسی تست نشده (adb فارسی تایپ نمی‌کند).
- **یک گوشی سامسونگ با USB وصل است.** همیشه `ANDROID_SERIAL=emulator-5554`.
- `PushMessagingService` اپ کلاینت منتظر فایل Firebase است.
- برچسب «مشتری تازه» در کارت صف اونر نام را کوتاه می‌کند.
- سؤال‌های قدیمی بی‌جواب: تخفیف استوری روی رزرو هم اعمال شود؟ استوری در وب مشتری هم باشد؟
- **دادهٔ تست محلی:**
  - سالن رزمریم `id=7`
  - مشتری `09390007001` با OTP `123456`
  - اونر دمو `09120000010` / `demo123456`
- **قاعدهٔ متن اپ:** کوتاه و بدون ئ ء ٔ أ.
- **این‌ها commit نشوند:**
  - `.claude/launch.json`، `mobile_owner/composeApp/build.gradle.kts`، lockهای `mobile_client/.gradle/`
  - فایل‌های untracked کاربر (`InMemoryUserLocalSource.kt`، `.claude/*`، `SALES_PLAYBOOK.md`، `demo-assets/`، `.mcp.json`، `docs/SERVER_DISK_CLEANUP.md`، `.graphifyignore`)
  - فایل‌ها را تک‌تک add کن.
- **محیط macOS:**
  - adb در `~/Library/Android/sdk/platform-tools/adb` است (در PATH نیست).
  - گریدل کلاینت: `java -classpath gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain` با `JAVA_HOME` = jbr اندروید استودیو.

# وضعیت فعلی

## هدف
P2 از `../PLAN_NEXT.md` روی برنچ `mobile-client` (worktree `../Noobatyar-mobile-client`). همهٔ کارهای ساختنی P2 تمام و merge شده‌اند. ادمین پیش‌فرض (unfold) برای موبایل درست شد و منویش کوتاه شد. پنل «نوا» ساخته و بعد revert شد، چون کاربر تصمیم گرفت فقط ادمین پیش‌فرض را بهتر کند. کاربر فعلاً نمی‌خواهد منتشر کند. قاعده: فقط تغییر افزایشی، چون کاربر واقعی و اپ قدیمی داریم.

## وضعیت
- **`mobile-client`:** push و دیپلوی نشده. develop و main دست نخورده‌اند.
- **تست‌ها:**
  - بک‌اند: ۹۸۲ تست.
  - اپ اونر: ۸۴ تست؛ اندروید، iOS و wasm compile می‌شوند.
  - اپ کلاینت: ۸۰ تست؛ اندروید و iOS compile می‌شوند.
  - وب: ۱۳ تست e2e.
- **P2 تمام‌شده:**
  - منبع نوبت
  - نمونه‌کار و مدارک (اونر، کلاینت، وب، ادمین)
  - نظرات (ثبت، گزارش، صفحهٔ اونر، پوش)
  - رتبه‌بندی
  - بنرها
  - بازاریابی
  - سرویس‌های سایت
  - لوگوی اجباری
  - رزرو نیتیو کلاینت و تب «نوبت‌های من» با ثبت واریز
  - «اولین نوبت خالی» (`first_free_slot`)
  - workflow جدا برای ریلیز کلاینت (`client-v*`)
- **ادمین:** روی موبایل overflow ندارد (داشبورد و گزارش مالی). منو شش بخش کوتاه دارد: بررسی، کاربران، رشد، پیام، مالی، سیستم. آدرس CSS نسخه‌دار است. پنل نوا revert شده (`60442df`).
- **روی AVD تست سرتاسری شده:** رزرو، کارت به کارت، لغو، نظرات کلاینت، بنر و نظرات اونر. بقیهٔ رابط کاربری جدید فقط باز شده و به‌طور کامل امتحان نشده.
- **محیط محلی:**
  - بک‌اند روی :8000 (preview `backend_mobile_client_mac`)
  - وب اونر روی :8081 (`mobile_owner_web_mobile_client_mac`)
  - سایت مشتری روی :3010
  - هر دو اپ روی Pixel_6a
  - حساب‌های تستی در `../Noobatyar-automation/TEST_ACCOUNTS.local.md`

## قدم‌های بعدی
1. (اختیاری) بهبود بیشتر ادمین پیش‌فرض: ثبت `LogEntry` برای کارهای داشبورد سفارشی، و چک موبایل صفحه‌های سفارشی با دادهٔ زیاد.
2. تست دستی رابط‌های جدید روی دستگاه:
   - برش و آپلود نمونه‌کار
   - دیالوگ نظر
   - واترمارک و گالری
   - پوش `NEW_REVIEW` با FCM واقعی
3. P3:
   - بخش `## client-vX.Y.Z` با بلوک fa در `CHANGELOG.md`
   - cron شبانهٔ `compute_rank_scores`
   - نسخهٔ جدید هر اپ
   - دیپلوی طبق `docs/DEPLOY_SCALE_HARDENING.md`
4. load test روی سرور واقعی (منتظر دسترسی SSH).

## مسائل باز
- ⚠️ **قبل از دیپلوی:** `ZIBAL_MERCHANT_ID` باید در `.env` سرور باشد. migrationهای P2 هم باید اجرا شوند (`versions/0003`، `visitor/0013`، `business/0032-0034`، `reviews`، `showcase`، `marketing`، `banners`).
- 🔒 رمز root سرور `93.127.223.93` در تاریخچهٔ git است و کاربر باید عوضش کند.
- ❓ اگر جلوی nginx یک CDN هست، `set_real_ip_from` لازم است.
- پوش `NEW_REVIEW` روی iOS و وب، صفحهٔ نظرات را باز نمی‌کند (فقط اندروید).
- workflow کلاینت هنوز اجرا نشده است. نام فایل FTP (`Noobatyar-client.apk`) حدسی است. `Config.xcconfig` کلاینت قدیمی است.
- `source_counts` آمار اونر هیچ صفحه‌ای ندارد که نشانش دهد.
- میانگین امتیاز در اپ اونر «۴.۲» است ولی در کلاینت «۴٫۴» (ممیز فارسی). باید یکسان شود.
- `PushMessagingService` اپ کلاینت در manifest ثبت نشده است (از قبل از این سشن).
- پیامک‌هایی که بعد از قبول provider با timeout قطع شوند refund می‌شوند. این یک نشت کوچک درآمد است.
- ابزار: `gradlew` با `sh` اجرا شود و `ANDROID_HOME` ست باشد. وقتی وب wasm اونر در حال اجراست، build اندروید اونر قفل می‌گیرد. کش محلی LocMem است و بعد از تغییر DB از shell باید سرور restart شود.
